# SmartShopPOS

## Smart and Simple POS for everyone

A scalable SaaS-ready Point of Sale platform designed for Kenyan businesses.

## Technology Stack

Backend:
- Fastify
- TypeScript
- Prisma
- PostgreSQL

Frontend:
- React
- TypeScript
- Vite

Infrastructure:
- Docker
- Redis
- Nginx

Features:
- Inventory management
- POS sales
- M-Pesa integration
- Paystack integration
- KRA eTIMS support
- Offline-first POS
- AI-powered business insights
