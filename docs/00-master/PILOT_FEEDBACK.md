# Pilot User Feedback Board

## Questions for Cashier Staff

1. **Was anything confusing?**
   - Which screen or action felt unclear?

2. **Which task took the longest?**
   - Product search? Adding to cart? Payment? Receipt?

3. **Which screen did you use the most?**
   - POS checkout? Dashboard? Reports?

4. **What did you expect that wasn't there?**
   - Missing shortcut, button, or feature?

5. **What would save you the most time?**
   - What's the biggest daily friction point?

## Questions for Managers

1. **Dashboard Clarity**
   - Can you find today's sales total in under 3 seconds?
   - Can you find low stock items without searching?
   - Are pending approvals obvious?

2. **Team Management**
   - Is it easy to track which cashier sold the most?
   - Can you see cash drawer status at a glance?

3. **Report Usability**
   - Which report answers your most common question?
   - Which report takes too long to find?

## Questions for Store Owners

1. **Financial Visibility**
   - Can you answer "How much money did we make today?" without clicking?
   - Can you see which products aren't moving?
   - Are supplier delivery issues visible?

2. **Business Questions**
   - Which products aren't moving?
   - Which supplier delivers late?
   - What's your best-selling product?
   - What's your average sale value?

## Metrics to Track

| Metric | Target |
|--------|--------|
| Time to open store | < 60 seconds |
| Time to complete a sale | < 20 seconds |
| Product search response | < 100 ms |
| Add item to cart | Instant |
| Payment dialog opens | < 150 ms |
| Dashboard load | < 2 seconds |
| Inventory search | < 100 ms |

## Feedback Collection Process

1. Deploy to demo environment
2. Share login with pilot users
3. Collect feedback via [feedback@smartshop.co.ke](mailto:feedback@smartshop.co.ke)
4. Prioritize issues tagged "blocks checkout"
5. Weekly review of top 3 feedback items
